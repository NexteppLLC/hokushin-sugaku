要点ようてん

解き方ときかたの選えらび方ほう（10秒びょうで決きめる）

  • ①「＝ 0」の形かたちにする。右辺うへんに数かずや式しきがあれば移項いこう・展開てんかいして整理せいりする（(x＋2)(x−3)＝6 のような形かたち）。
  • ② 因数分解いんすうぶんかいできる？「かけて c、たして b」の2数かずがある／共通因数きょうつういんすうがある／x² − a² の形かたち → 因数分解いんすうぶんかいで解とく。
  • ③ できなければ解の公式かいのこうしき。x² ＝ k や (x＋m)² ＝ k の形かたちは平方根へいほうこんの考かんがえで直接ちょくせつ。
  • 解かいは2つ出でるのがふつう。1つしか出でない（重解じゅうかい）・√がつく・分数ぶんすうになる、どれも正せいしい答こたえになりうる。

因数分解いんすうぶんかいで解とく

  • x² ＋ (a＋b)x ＋ ab ＝ (x＋a)(x＋b)：「かけて定数項ていすうこう、たして x の係数けいすう」の2数かずをさがす。
  • x² − 5x ＋ 6 → −2 と −3 → (x−2)(x−3)＝0 → x＝2，3。符号ふごうは因数分解いんすうぶんかいした( )の中なかと反対はんたいになる。
  • 共通因数きょうつういんすう：x² ＋ 7x ＝ x(x＋7)。両辺りょうへんを x で割わりらない（x＝0 が消きえる）。
  • x² − 16 ＝ (x＋4)(x−4)、x² ＋ 6x ＋ 9 ＝ (x＋3)²（解かいは −3 の1つ）。

平方根へいほうこんの考かんがえで解とく

  • x² ＝ k → x ＝ ±√k（k の平方根へいほうこん）。3x² ＝ 24 のように係数けいすうがあればまず割わって x² ＝ 8、x ＝ ±2√2。
  • (x ＋ m)² ＝ k → x ＋ m ＝ ±√k → x ＝ −m ± √k。(x−4)²＝5 なら x ＝ 4 ± √5。
  • √の中なかはいつも簡単かんたんにする：√12 → 2√3、√20 → 2√5、√8 → 2√2。

解の公式かいのこうしき

  • ax² ＋ bx ＋ c ＝ 0 のとき　x ＝ −b ± √b² − 4ac2a
  • 手順てじゅん：① a，b，c を書き出かきだす（符号ふごうごと） ② √の中なか b² − 4ac を先さきに計算けいさん ③ 分母ぶんぼ 2a を書かく ④ 約分やくぶんは分子ぶんしの両方りょうほうの項こうと分母ぶんぼで。
  • b が負ふのとき：−b は正せい、b² は正せい。x² − 5x ＋ 3 ＝ 0 → x ＝ 5 ± √132。
  • √の中なかが平方数へいほうすう（49 など）になったら√がはずれて整数せいすう・分数ぶんすうの解かいになる（本当ほんとうは因数分解いんすうぶんかいできた問題もんだい）。

ミスを防ふせぐ3つの習慣しゅうかん

  • 解かいが出でたら1つは代入だいにゅうして確たしかめる（4点てん問題もんだいを落おとさない最短さいたんの方法ほうほう）。
  • 「かけて c、たして b」を探さがすときは c の符号ふごうから：c ＞ 0 なら同符号どうふごうの2数かず、c ＜ 0 なら異符号いふごう。
  • 答こたえは「x ＝ 2，3」「x ＝ 1 ± √5」のように2つの解かいをまとめて書かく。「または」でもよい。

基礎きそ因数分解いんすうぶんかい
次つぎの二次方程式にじほうていしきを解ときなさい。
x² − 5x ＋ 6 ＝ 0

答こたえx ＝ 2，3

解説かいせつ「かけて 6、たして −5」になる2数かずは −2 と −3。左辺さへんを因数分解いんすうぶんかいして (x − 2)(x − 3) ＝ 0。「AB ＝ 0 なら A ＝ 0 または B ＝ 0」だから x − 2 ＝ 0 または x − 3 ＝ 0。答こたえは x ＝ 2，3 のように2つとも書かく。

平方根へいほうこんの基本きほん

  • a の平方根へいほうこん＝2乗じょうすると a になる数かずで、正せいと負ふの2つ（±√a）。√a は正せいの方ほうだけ。√a² ＝ a（a ＞ 0）、(√a)² ＝ a。
  • √の中なかを小ちいさく：√48 ＝ √(16 × 3) ＝ 4√3。平方数へいほうすう（4，9，16，25，36，49，64，81，100，121，144，169，196，225）で割われるか探さがす。
  • 外そとの数かずを中なかに入いれる：2√6 ＝ √(2² × 6) ＝ √24。大小だいしょう比較ひかく・整数部分せいすうぶぶんはこの形かたちにそろえる。

√が自然数しぜんすう（整数せいすう）になる条件じょうけん

  • √n が自然数しぜんすう ⇔ n が平方数へいほうすう。
  • √(kn) が自然数しぜんすうになる最小さいしょうの n：k を素因数分解そいんすうぶんかいし、奇数きすう個こある素因数そいんすうをかけて偶数ぐうすう個こにする。√20n → 20 ＝ 2² × 5 → n ＝ 5。
  • 分数ぶんすうの形かたち √knm：分母ぶんぼ m を消けすための m の倍数ばいすうと、奇数きすう個この素因数そいんすうの両方りょうほうをかける。√20n ／ 3 → n ＝ 3 × 5 ＝ 15。
  • √(k／n)：k ÷ n が平方数へいほうすうになる n を「k の約数やくすう」から探さがす。√(k − n)：k − n が k より小ちいさい平方数へいほうすうになる n を数かぞえる。

大小だいしょう・整数部分せいすうぶぶん・範囲はんい

  • 大小だいしょうは全部ぜんぶ√の中なかで比くらべる（3 ＝ √9）。負の数ふのかずは絶対値ぜったいちが大おおきいほど小ちいさい。
  • √n の整数部分せいすうぶぶんが a ⇔ a² ≦ n ＜ (a ＋ 1)²。√40 → 36 ≦ 40 ＜ 49 → 6。
  • a ＜ √n ＜ b を満みたす n ⇔ a² ＜ n ＜ b²。個数こすうは「両端りょうはしをふくむか」で決きまる（4 ＜ √n ＜ 5 → 17〜24 の 8 個こ）。
  • 近似値きんじち：√2 ≒ 1.414，√3 ≒ 1.732，√5 ≒ 2.236。√50 ＝ 5√2、√0.5 ＝ √22 のように、与あたえられた√の形かたちに直なおしてから使つかう。

計算けいさん・式の値しきのあたい

  • 有理化ゆうりか：分母ぶんぼと同おなじ√を分母ぶんぼ・分子ぶんしにかける。6√3 ＝ 6√33 ＝ 2√3。約分やくぶんを忘わすれない。
  • 乗法公式じょうほうこうしきはそのまま使つかえる：(√a ＋ √b)(√a − √b) ＝ a − b、(√a − b)² ＝ a − 2b√a ＋ b²。
  • 式の値しきのあたいは因数分解いんすうぶんかいしてから代入だいにゅう：x² − 4x ＋ 4 ＝ (x − 2)²、a² − b² ＝ (a ＋ b)(a − b)。

要点ようてん

比例ひれい・反比例はんぴれいの式しき・グラフ・変域へんいき

  • 比例ひれい y ＝ ax：原点げんてんを通とおる直線ちょくせん。a ＞ 0 で右上みぎあがり、a ＜ 0 で右下みぎさがり。1 点てんから a ＝ y ÷ x。
  • 反比例はんぴれい y ＝ax（xy ＝ a）：双そう曲線きょくせん。a ＞ 0 なら右上みぎうえと左下ひだりした、a ＜ 0 なら左上ひだりうえと右下みぎしたの 2 本ほん。1 点てんから a ＝ x × y。原点げんてんも x 軸じく・y 軸じくも通とおらない。
  • グラフから a を読よむ：x，y がともに整数せいすうの点てんを 1 つ見みつけ、比例ひれいなら y ÷ x、反比例はんぴれいなら x × y。
  • 変域へんいき：x の両端りょうたんの値あたいを代入だいにゅうして y を 2 つ求もとめ、小ちいさい方ほう ≦ y ≦ 大おおきい方ほう。a ＜ 0 の比例ひれいでは大小だいしょうが入いれかわる。反比例はんぴれいは x の変域へんいきが 0 をふくまないときだけ変域へんいきが決きまる。

変化の割合へんかのわりあいと文章ぶんしょう題だい（積せきが一定いってい）

  • 変化の割合へんかのわりあい ＝y の増加ぞうか量りょうx の増加ぞうか量りょう。増加ぞうか量りょう ＝（あとの値あたい）−（前まえの値あたい）。反比例はんぴれいは区間くかんによって変化の割合へんかのわりあいが変かわる（一次関数いちじかんすうは一定いっていで a）。
  • 反比例はんぴれいになる文章ぶんしょう題だい：歯数はすう × 回転かいてん数すう、速はやさ ×時間じかん（道みちのりが一定いってい）、1 分ふんあたりの水量すいりょう ×時間じかん（容積ようせきが一定いってい）、縦たて × 横よこ（面積めんせきが一定いってい）。「積せきが一定いってい ＝ a」を見みつけて y ＝ax。
  • 2 つのグラフの両方りょうほうの上うえにある点てん → 2 つの式しきを連立れんりつする。反比例はんぴれいと一次関数いちじかんすうの交点こうてんは、両辺りょうへんに x をかけて二次方程式にじほうていしきにして解とく。
  • 式しきに代入だいにゅうするときは (x，y) の順じゅんをまちがえない。答こたえは「y ＝ …」「a ＝ …」「(−2, −6)」など、聞きかれた形かたちで書かく。
